# Respaldo PriorIA V4.3

Paquete ejecutable del simulador de indicadores V4.3, previo a los cambios de distribución de llegadas y al desglose posterior de tiempos de categorización.

El ZIP contiene el proyecto FastAPI + Docker Compose + Canvas en la estructura necesaria para ejecutarlo. Configuración del escenario original: C1 2%; llegada por Carabineros 15%; ambulancia 5%; propios medios 80%.
